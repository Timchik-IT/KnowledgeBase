Машинное обучение - алгоритмы анализа данные с целью нахождения в них закономерностей. На основе которых и будет обучение [[Искусственный интеллект|ИИ]].

В нем используются методы нейросетей, статистики, исследования операции и тд.

Классическое обучение делится на два вида:
1. С учителем -> Данные заранее категорированные 
	1. Предсказать категорию -> Классификация
	2. Предсказать значение -> Регрессия 
2. Без учителя -> Данные никак не размечены
	1. Разделить по схожести -> Кластеризация
	2. Найти зависимости -> Уменьшение размерности (обобщение)
	3. Выявить последовательности -> Ассоциация
