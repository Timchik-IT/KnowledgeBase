[[Основы робототехники]]


## 7 популярных симуляторов
| Симулятор | Кратко |
|---|---|
| **Gazebo** | Классика ROS, физика ODE/Bullet/DART |
| **Ignition** | Новое поколение Gazebo (Gazebo Sim) |
| **Webots** | Проприетарный, но удобный, много готовых моделей |
| **MuJoCo** | Быстрая физика, популярен в RL |
| **Bullet** | Физический движок, используется во многих средах |
| **CoppeliaSim** | Ранее V-REP, мощный GUI, скриптинг |
| **NVIDIA Isaac** | GPU-ускорение, фотореализм, AI/RL |
## Для чего нужны симуляторы?
- **Создание и тестирование алгоритмов** — отладка без риска для железа
- **Прототипирование и проектирование** — проверка конструкции до сборки
- **Безопасные эксперименты** — опасные сценарии без последствий
- **Видео-демо роботов** — презентации и визуализация
- **Использование моделей недоступных роботов** — работа с дорогим/редким оборудованием
- **Конструирование особых окружений** — сцены, которые сложно собрать в реальности
- **Образование** — обучение студентов и разработчиков
- **Обучение с подкреплением (RL)** — миллионы эпизодов за считанные часы
