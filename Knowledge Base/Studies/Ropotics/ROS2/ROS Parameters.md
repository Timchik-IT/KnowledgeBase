**Параметры** в ROS 2 представляют собой значения конфигурации, связанные с отдельными [[ROS Node|нодами]], что позволяет динамически корректировать поведение узла без изменения его исходного кода. Они служат настройками, к которым можно получить доступ и изменить во время выполнения или настроить при запуске.

### **Основные характеристики параметров ROS 2:**
#### Специфические для узла: 
Каждый узел поддерживает свой собственный набор параметров.
#### Типы данных: 
Параметры могут быть целыми числами, числами с плавающей точкой, логическими значениями, строками или массивами этих типов. 
#### Динамическая настраиваемость: 
Параметры можно изменять во время работы ноды, что позволяет вносить коррективы во время выполнения.
#### **Persistence**: 
Значения параметров можно сохранять в файлах YAML и перезагружать при перезапуске ноды, что позволяет обеспечивать единообразие конфигураций между сеансами.

### **Работа с параметрами ROS 2:**

#### Заявление: 
Параметры обычно объявляются в коде узла, часто со значениями по умолчанию и описаниями.
#### Доступ и изменение:
- **Инструменты командной строки:** 
	инструмент ros2 paramкомандной строки предоставляет функции для перечисления, получения, установки, сброса и загрузки параметров.
- **Программный доступ:** 
	узлы могут взаимодействовать со своими собственными параметрами или параметрами других узлов, используя API ROS 2, что обычно включает вызовы служб.
- **Файлы YAML:** 
	параметры можно определять и загружать из файлов конфигурации YAML, особенно для начальных конфигураций узлов.
#### Обратные вызовы: 
ROS 2 позволяет регистрировать обратные вызовы для реагирования на изменения параметров, что позволяет выполнять пользовательскую логику при изменении значения параметра. Это включает в себя обратные вызовы до, после и после установки параметров.

### **Работа с параметрами:**
Параметры списка.
``` bash
ros2 param list
```

Получить значение параметра.
``` bash
ros2 param get <node_name> <parameter_name>
```

Установите значение параметра.
``` bash
ros2 param set <node_name> <parameter_name> <new_value>
```

Промиотр всех параметров ноды.
``` bash
ros2 param dump <node_name>
```

Сохранение параметров в файле.
``` bash
ros2 param dump <node_name> > my_params.yaml
```

Загрузить параметры из файла.
``` bash
ros2 param load <node_name> my_params.yaml
```
