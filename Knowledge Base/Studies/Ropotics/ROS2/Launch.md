Чтобы запустить файл в [[Ros2]], используйте `ros2 launch`команду, за которой следует имя пакета и имя файла запуска.

Launch файлы нужны для оптимизации запуска. Заменяют работу в консоли. Чтобы не прописывать вручную файлы которые надо запустить, мы запускаем один launch файл который стартует все нужные нам файлы.

### Действия по запуску файла в ROS 2:

- **Перейдите в рабочее пространство ROS 2:** откройте терминал и измените свой каталог на корневой каталог рабочего пространства ROS 2.
``` bash
cd ~/ros2_ws
```

- **Получите файлы настройки ROS 2:** это гарантирует, что переменные среды будут правильно настроены для ROS 2.

``` bash
source install/setup.bash
```

- **Выполнить файл запуска:** используйте `ros2 launch`команду, указав пакет, содержащий файл запуска, и сам файл запуска.

``` bash
ros2 launch <package_name> <launch_file_name>.py
```

- Замените `<package_name>`на имя пакета ROS 2, в котором находится ваш файл запуска.
- Замените `<launch_file_name>.py`фактическим именем вашего файла запуска на основе Python (например, `turtlesim_mimic_launch.py`).



Пример:

Если у вас есть файл запуска `my_robot_launch.py`внутри пакета с именем `my_robot_bringup`, вы можете запустить его следующим образом:

``` bash
ros2 launch my_robot_bringup my_robot_launch.py
```

Эта команда выполнит скрипт Python, определенный в `my_robot_launch.py`, который, в свою очередь, запустит и настроит узлы ROS 2, как указано в файле запуска.
