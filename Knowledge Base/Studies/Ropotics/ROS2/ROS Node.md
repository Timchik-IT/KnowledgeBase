В [[Ros2]] нода — это фундаментальная вычислительная единица в графе ROS. По сути, это исполняемая программа, выполняющая определённую модульную задачу в робототехнической системе. Узлы представляют собой независимые процессы, взаимодействующие друг с другом для обеспечения общей функциональности робота.

Вот краткое описание того, что представляет собой нода ROS 2:

### **Модульные вычисления:** 
   
Каждый узел обычно выполняет одну логическую функцию. Например, один узел может отвечать за считывание данных с датчиков, другой — за управление двигателями, а третий — за планирование маршрута. Такая модульность способствует повторному использованию кода и упрощает разработку и отладку системы.

### **Связь с другими узлами:** 

Узлы взаимодействуют друг с другом посредством различных механизмов связи:    
- **Topics:** Для асинхронной потоковой передачи данных «один ко многим» (например, публикация показаний датчиков, подписка на команды двигателя).
- **Actions:** для синхронных взаимодействий типа «запрос-ответ» (например, запрос определенного вычисления, получение результата).
- **Действия:** для длительных, ориентированных на цель задач с обратной связью и возможностями упреждения (например, отдача команды роботу на перемещение в определенное место).
- **Parameters:** позволяют настраивать параметры выполнения и изменять поведение узла.

### **Команды взаимодействия с нодами:**

#### 1. Помощь взаимодействия
``` bash
ros2 node -h
```
#### 2. Список текущих запущенных нод
``` bash
ros2 node list
```
#### 3. Запустить ноду
``` bash
ros2 run <pkg> <node_name>

ex:
ros2 run turtlesim tortlesim_node
```
#### 4. Вывести информацию о запущенной ноде
``` bash
ros2 node info <node_name>
```
