В [[Ros2]] **топик** служит каналом связи внутри графа ROS, позволяя [[ROS Node|нодам]] обмениваться сообщениями. **Топики** являются фундаментальным элементом модели коммуникации «публикация/подписка» в ROS 2.

![Ros2 part 5 - Create a ROS2 Topic: Publisher and Subscriber Nodes in Python  and C++](https://www.roboticsunveiled.com/wp-content/uploads/2024/04/Screenshot-from-2024-04-13-00-47-35.png)

### **Модель публикации/подписки:** 

**Ноды** могут выступать в роли издателей, создавая и отправляя данные по определенным **топикам**, и/или подписчиков, получая и потребляя данные из **топиков**.

### **Обмен сообщениями:** 

Данные, передаваемые по **топикам**, называются сообщениями. Эти сообщения определяются `.msg`файлами, в которых указаны поля данных и их типы.

### **Непрерывные потоки данных:** 

**Топики** хорошо подходят для непрерывных потоков данных, таких как данные датчиков (например, данные с камер, лидарное сканирование) или информация о состоянии робота (например, положение суставов, одометрия).

### **Анонимное сообщение:** 

Издатели и подписчики не знакомы друг с другом напрямую. Они общаются косвенно, договариваясь через **топики**.

### **Гибкие соединения:** 

**Топики** поддерживают различные модели коммуникации, включая соединения «один к одному», «один ко многим», «многие к одному» и «многие ко многим» между издателями и подписчиками.

### **Инструменты командной строки:** 

ROS 2 предоставляет инструменты командной строки для взаимодействия с такими темами, как:

#### 1. Список всех активных топиков.
``` bash
ros2 topic list
```
Детальный просмотр доступен с фалгом `-t`
``` bash
ros2 topic list -t
```
#### 2. Отображает сообщения, публикуемые по определенной теме.
``` bash
ros2 topic echo <topic_name>
``` 
#### 3. Просмотр информации о конкретном топике.
``` bash
ros2 topic info <topic_name>
```
#### 4. Просмотр интерфейса сообщения.
``` bash
ros2 topic interface show <type>
```
#### 5. Публикация сообщения в топик.
``` bash
ros2 topic pub --once <topic name> <msg_type> '<args>'
```
С определенной частотой:
``` bash
ros2 topic bub --rate <number> <topic name> <msg_type> '<args>'
```
#### 6. Показывает скорость публикации темы. 
``` bash
ros2 topic hz <topic_name>
```
#### 7. Можно просмотреть rqt граф, который покажет полное взаимодействие. **Визуализация**.
``` bash
rqt_graph
```
