# Ros 2 (Robot Operating System 2)

## Общая информация
- **ROS 2** — это вторая версия Robot Operating System, фреймворка для разработки программного обеспечения для роботов.
- Является **не операционной системой**, а набором библиотек и инструментов.
- Основан на принципах **модульности**, **распределённости** и **реального времени**
## Основные отличия от Ros 1
| Характеристика    | ROS 1                 | ROS 2                           |
| ----------------- | --------------------- | ------------------------------- |
| Миддлвар          | ROS Master + TCPROS   | DDS (Data Distribution Service) |
| Поддержка RTOS    | Нет                   | Да                              |
| Безопасность      | Отсутствует           | Встроенные механизмы (SROS2)    |
| Языки             | В основном Python/C++ | Python, C++, Rust, JavaScript   |
| Поддержка Windows | Ограниченная          | Полная                          |

## Архитектура
- **Узлы (Nodes)** — исполняемые процессы, общающиеся через топики, сервисы и параметры.
- **Топики (Topics)** — асинхронная передача сообщений (publish/subscribe).
- **Сервисы (Services)** — синхронный запрос-ответ.
- **Параметры (Parameters)** — настройки узлов во время выполнения.
- **Действия (Actions)** — асинхронные задачи с возможностью отмены и прогресса.

## Основные команды CLI

- `ros2 run <package> <executable>` — запуск узла.
- `ros2 topic list` — список топиков.
- `ros2 node list` — список активных узлов.
- `ros2 launch <package> <launch_file>` — запуск через launch-файл.
