Рабочее пространство ROS 2 — это фундаментальная структура каталогов, используемая для организации, сборки и разработки пакетов [[Ros2]]. Оно служит центральным хранилищем всех компонентов программного обеспечения робота, включая исходный код, файлы данных и скрипты конфигурации.

Ключевые компоненты рабочего пространства ROS 2:

- **Корневой каталог:** 
    
    Это основная папка, охватывающая всё рабочее пространство. Например, `~/ros2_ws`.
    
- `src`Каталог: 
    
    Расположенный в корневом каталоге, этот файл содержит исходный код пакетов ROS 2. Каждый пакет обычно находится в собственном подкаталоге внутри `src`.
    
- `build`Каталог: 
    
    Этот каталог автоматически создается системой сборки ( `colcon`) и содержит промежуточные файлы сборки.
    
- `install`Каталог: 
    
    Этот каталог, также созданный с помощью `colcon`, содержит финальные установленные файлы ваших пакетов, включая исполняемые файлы, библиотеки и файлы конфигурации. Он также содержит `setup.bash`скрипт (или его эквивалент для других оболочек), который вы используете для обеспечения доступности пакетов рабочей области в вашей среде.
    
- `log`Каталог: 
    
    В этом каталоге хранятся журналы сборки и другая важная информация.

### Создание и использование рабочего пространства:

- Создайте рабочее пространство.
``` bash
mkdir -p ~/ros2_ws/src
```

- **Заполнить пакетами:** поместите исходный код пакета ROS 2 в `~/ros2_ws/src `каталог.
- **Создайте рабочее пространство:** перейдите в корень вашего рабочего пространства и используйте его `colcon build` для компиляции ваших пакетов.
``` bash
cd ~/ros2_ws
colcon build
```

- Так-же можно сбилдить определенный пакет.
``` bash
colcon buid --packages-select <pkg_name> 
```

- **Источник рабочей области:** После сборки выберите `setup.bash`скрипт из `install`каталога, чтобы сделать ваши пакеты доступными в текущем сеансе терминала.
``` bash
source install/setup.bash
```

### Создание своих собственных пакетов

- Создание пакета с нодой на плюсах
``` bash
ros2 pkg create --build-type ament_cmake --node-name <node_name> <pkg_name>
```
- Создание пакета с нодой на питоне
``` bash
ros2 pkg create --build-type ament_python <pkg_name>
```
